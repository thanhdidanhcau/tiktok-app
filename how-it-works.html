How it works

From a finished video to a published TikTok post, in five steps.

  1. Prepare the video

    The creator edits a short 9:16 clip and saves it in a private cloud folder.

  2. Plan the schedule

    A spreadsheet row holds the file name, publish date and time, and the caption. Two slots per day can be filled in automatically, or typed by hand.

  3. Authorize once

    The creator signs in with TikTok through Login Kit and approves the requested scopes. The resulting tokens are stored privately and refreshed when they expire.

  4. Publish at the planned time

    The tool reads the creator's allowed privacy options, starts a Direct Post with the caption, uploads the video file, then checks the publish status until TikTok reports it complete.

  5. Record the result

    The publish ID and time are written back to the spreadsheet and the row is marked as published, so the same video is never posted twice.

TikTok API calls used

These are the only TikTok endpoints the tool calls.

EndpointPurpose
/v2/oauth/token/Exchange the authorization code for tokens and refresh the access token.
/v2/post/publish/creator_info/query/Read the creator's allowed privacy options before posting.
/v2/post/publish/video/init/Start a Direct Post with the caption and file size.
Upload URL returned by initSend the video file to TikTok.
/v2/post/publish/status/fetch/Check whether the post has been published.

What the tool does not do

  • It does not read, scrape or store other people's videos, comments or profiles.
  • It does not like, follow, comment or send messages on the creator's behalf.
  • It does not post content that the creator did not make.
  • It does not collect data about viewers or followers.
