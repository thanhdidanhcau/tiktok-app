Creator tool

Publish badminton highlights to TikTok on schedule

The Thành Đi Đánh Cầu posting tool lets the channel owner plan short vertical videos in a spreadsheet and publishes them to their own TikTok account at the planned time, using TikTok's official Content Posting API.

See how it works Privacy Policy

What the tool does

Thành Đi Đánh Cầu is a recreational badminton channel. It shares short rally highlights recorded at weekly games, usually 10 to 30 seconds long, in 9:16 vertical format.

Plan in a spreadsheet

Every video gets one row: file name, publish date and time, and caption. The next days' slots can be filled in with one click.

Publish through the official API

At the planned time the tool uploads the video file and publishes it to the creator's own profile with Direct Post.

Keep a clear record

After publishing, the tool checks the status with TikTok and writes the result back to the sheet, so the creator always sees what is live.

TikTok integration

The tool requests only the products and scopes below.

ProductScopeHow it is used
Login Kit user.info.basic One-time authorization so the tool can act for the creator's own TikTok account.
Content Posting API (Direct Post) video.publish Publishes the creator's own video to their own profile at the scheduled time.

The video.upload scope is bundled with the Content Posting API product. This tool does not use it.

Your data

  • Authorization tokens are kept in private storage that only the creator's Google account can open.
  • The tool does not read or collect data about viewers, followers or other TikTok users.
  • Nothing is sold or shared with third parties.
  • Access can be revoked at any time from TikTok settings.
